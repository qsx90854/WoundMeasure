# 兩張圖片量測

啟動 GradSIFTDebug 主程式，選「載入左／右兩張圖片」，依序選擇 UI 左圖、UI 右圖。
支援 PNG、JPG/JPEG、BMP、TIF/TIFF，含中文路徑。取消選檔會留在來源選單。

請提供同一已標定相機、相同影像尺寸、尚未去畸變的原圖；拍照解析度與裁切／數位縮放需符合目前標定內參。
載入不縮放、不依 EXIF 自動旋轉；兩圖尺寸不同會拒絕。為避免額外壓縮誤差，實驗可優先使用無損 PNG。

內部固定 A/F0=右圖、B/F1=左圖，直接傳入原始影格陣列，不轉存影片。
停用角度選幀、候選擴充與時間鄰域選幀，其餘 ArUco/RT、去畸變、基準平面及量測流程沿用主程式。
仍需可估計 RT 的 ArUco 與符合原設定的基線。只有兩張圖片，沒有額外影片影格可用於時序追蹤或多影格融合。

每次載入在 RECORD_SAVE_DIR 下建立 image_pair_時間戳記 資料夾。
image_pair.json 記錄來源左右圖路徑、尺寸、內參檔案及角色，既有量測文字輸出使用同目錄的 image_pair.txt。
不覆寫原圖片。

反光比較需要四張圖：固定左視角的有／無反光，固定右視角的有／無反光。
分別載入「無反光左＋無反光右」和「有反光左＋有反光右」做比較。
本功能每組仍會重新估計 RT；若要完全隔離匹配算法誤差，後續實驗還需控制或比較各組 RT／基準平面的差異。
