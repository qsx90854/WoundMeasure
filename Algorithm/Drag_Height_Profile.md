# 拖曳傷口高度剖面

主程式：`depth_measure_multi_aruco_sbs_camera_v7_demo_zebra_GradSIFTDebug.py`

## 使用方式

1. 啟用 Region-SIFT，確認目前左右圖及高度基準平面。
2. 按主 UI 的「拖曳高度剖面」（左側設定區、SIFT 參數按鈕上方）。
3. 在左圖按住滑鼠左鍵畫一條路徑，放開後開始依拖曳順序逐點計算。
4. 左圖顯示點編號及 Wound Height（mm）；計算結束自動開啟折線圖。
5. 點右圖對應的點、左圖的點，或折線圖的點序號，切換該點的下方 Debug 與 Region-SIFT ambiguity diagnostics。此操作讀取保存的結果，不重新匹配。
6. 在左圖遠離既有點的位置重新拖曳，可取代上一條剖面。再次按按鈕或在主視窗按 Esc 可退出並清除本次剖面。

計算中按按鈕或 Esc，會於當前點計算結束後停止，保留已完成部分供檢視。退出模式後才恢復參數與影格控制；已開啟的 SIFT 參數視窗也無法在剖面模式內套用修改。

## 點與折線的意義

- 左圖每點讀取既有量測流程的 `height_display_mm`，沿用一般點擊的 Wound Height 與平面/多影格規則，不改變匹配算法。
- 橫軸是取樣點編號，縱軸是 Wound Height（mm）。取樣距離是影像像素，不是表面物理距離。
- 量測失敗以 FAIL 標示，折線留空；底部的紅叉只表示失敗，並非零高度。
- 右圖的普通點是目前顯示影格的匹配點。紫色叉號 `編號?` 是被拒絕的最佳候選，不能當成有效匹配；若根本沒有候選位置，請改從左圖或折線選該點。
- 診斷對應目前顯示的右圖（BEST 配對）。若一般量測流程採用其他影格或融合高度，折線的 Wound Height 不一定等於診斷視窗中單一候選的高度。
- 診斷資料暫存於本機暫存目錄，重新拖曳、退出模式或關閉主視窗會清除；本功能不自動輸出永久 CSV/XLSX。

## 可調參數

主程式 `DRAG_PROFILE_CONFIG`：

```python
DRAG_PROFILE_CONFIG = DragProfileConfig(
    spacing_px=20.0,      # 沿軌跡取樣間距，影像像素
    max_points=100,       # 太長的路徑自動放大間距以限制總點數
    pick_radius_px=12.0,  # 回放時點選容許距離，螢幕像素
)
```

取樣包含起終點；最後一段可短於設定間距，座標四捨五入到整數像素。計算總時間約隨取樣點數增加，每點仍走原本的量測流程。
